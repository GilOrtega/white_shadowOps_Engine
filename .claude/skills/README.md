# Skills para Claude Code

Skills de video corto tomadas de [JustCarlos30/skills-videos-cortos](https://github.com/JustCarlos30/skills-videos-cortos)
(MIT, © 2026 Carlos Jarero — ver `LICENSE-skills-videos-cortos`). Se activan solas cuando trabajas en este repo con Claude Code.

| Skill | Para qué |
|---|---|
| `cuestionar-guion` | Crítica franca de un guion antes de grabar (la misma lógica del botón "Critícame este guion" en /contenido). |
| `voz-whisper` | Limpia audio con FFmpeg, transcribe en local con whisper.cpp y corta silencios. Requiere `ffmpeg`, `whisper-cli` y un modelo ggml en tu máquina. Base para el render del motor de Shorts. |
| `motion` | Diseño y revisión de animación en Remotion (para intros o el contador del reto, más adelante). |

No incluye recursos de audio, fuentes ni modelos: esos tienen su propia licencia.
